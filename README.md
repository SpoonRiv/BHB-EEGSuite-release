# BHB EEGSuite

EEG 采集、阻抗检测、数据录制与浏览器实时可视化的一体化软件。下载即用，无需安装任何编程环境。

***

## 三步开始

1. **下载**：到 [Releases 页面](https://github.com/SpoonRiv/BHB-EEGSuite-release/releases/latest) 下载 `BHB-EEGSuite-base.zip`
2. **解压**：右键 ZIP → 全部解压 → 选一个可写的目录（如 `D:\BHB-EEGSuite`），不要解压到桌面或 C 盘系统目录
3. **运行**：进入解压后的文件夹，双击 `BHB-EEGSuite.exe`

首次启动约需 10–30 秒（正在初始化运行环境），随后会自动打开浏览器进入软件主页。如果浏览器没自动弹出，手动访问 http://127.0.0.1:8001/ 即可。

***

## 系统要求

- Windows 11（64 位）
- 必须完整解压后再运行，**不要在 ZIP 压缩包里直接双击 exe**
- 解压目录要可写（用来保存配置、模块、实验数据），建议放在 D 盘根目录或 `文档` 文件夹下
- 若启动时弹出"缺少 dll"或"无法启动"，请安装 [Microsoft Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe) 后重试

***

## 软件功能

启动后会先进入**设备页**：扫描并连接蓝牙采集设备，选择通道组合后点击「应用到系统」，自动跳转到模式页。

模式页提供三种工作模式：

| 模式 | 用途 |
|---|---|
| **EEG** | 实时脑电波形显示 + 离线录制，停止后可导出 CSV / EDF（支持带通滤波） |
| **阻抗** | 周期性刷新各通道阻抗，用颜色直观反映电极接触质量 |
| **tDCS** | 经颅电刺激控制：开/停刺激、下发指令、监测电流/电压/故障/电量 |

**音乐范式模块**（可选）：文本-音频多模态范式默认不安装，模式页最右侧显示灰色入口。在右上角「模块管理」里点一下就能在线下载安装，不需要再单独下载文件。

## 常见问题

### 启动报错 "address 8001" / 端口被占用

最常见，通常是上次没正常退出、后台还有残留进程。**直接重启电脑**，再双击 exe 即可。

### 双击 exe 没反应 / 黑框一闪就关

1. 确认是**解压后**运行，不是在 ZIP 里双击
2. 右键 exe → 以管理员身份运行
3. 检查是否解压到了只读目录（换到 D 盘根目录重试）
4. 重启电脑后再试

### 浏览器没自动弹出 / 页面打不开

1. 手动访问 http://127.0.0.1:8001/
2. 看任务管理器里是否有 `BHB-EEGSuite.exe` 在运行——没运行就再双击 exe
3. 第一次启动时如果系统弹出防火墙提示，点"允许访问"
4. 重启电脑后再试

### 连不上蓝牙设备 / 没有波形

1. 确认采集设备已开机、电量充足
2. 确认电脑蓝牙已打开
3. 把设备靠近电脑（1 米内）
4. 重启采集设备 + 重启电脑后重试
5. 模式页点击「开始」后才会有波形，不点不采集

### 录制后导出失败

1. 确认磁盘空间充足（至少留几个 G）
2. 确认解压目录可写
3. 先试导出 CSV，能导出说明录制成功；EDF 失败通常是磁盘空间或目录权限问题
4. 重启电脑后重新录制一段再导出

### 还是搞不定

重启电脑能解决 80% 的问题。重启后仍不行的，记录下：
- 报错文字（截图或抄写）
- 出错的页面（设备页/EEG/阻抗/tDCS）
- 重复操作能否复现

联系开发者反馈以上信息。

## 关于版本

软件顶栏会显示当前版本号（如 `3.5.8`）。新版本发布后，到 [Releases 页面](https://github.com/SpoonRiv/BHB-EEGSuite-release/releases) 下载新的 `BHB-EEGSuite-base.zip` 解压覆盖即可升级，本机配置和数据不会丢失（解压到不同目录更保险）。
